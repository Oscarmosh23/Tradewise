⚡ Scalping Risk Rules
01
Only trade MTF AGREEMENT signals — never conflicts
The platform now automatically filters. When 5min and 15min disagree it shows WAIT — not a tradeable signal. Only enter on STRONG BUY or STRONG SELL with both timeframes aligned.
02
0.5% risk per trade maximum for scalping
Scalping = multiple trades per session. 0.5% risk × 10 trades = 5% max daily risk. If you lose 2% stop for the day. Discipline over revenge trading.
03
Minimum 2:1 reward to risk — 10 pip stop, 20 pip target
XAUUSD: stop 10 pips, target 20 pips. EURUSD: stop 8 pips, target 16 pips. Never take a trade with less than 2:1 R:R. The math only works when you let winners run.
04
Move stop to breakeven at +10 pips profit
Once price moves 10 pips in your favor, move stop loss to entry price. You now cannot lose. This is called a free trade and it is the most important scalping habit.
05
Stop after 3 consecutive losses
Three losses means market conditions changed. Stop for 30 minutes minimum. Come back with fresh eyes. Never revenge trade.

Add EMA 8 and EMA 21 to BOTH charts
Insert → Indicators → Trend → Moving Average → EMA period 8 (blue). Repeat for EMA 21 (red). EMA 8 above EMA 21 = bullish. EMA 8 below EMA 21 = bearish. Both charts must agree.
Insert → MA → EMA 8 (blue) + EMA 21 (red)
03
Wait for TradeWise STRONG BUY or STRONG SELL
Only act when TradeWise shows STRONG BUY or STRONG SELL — meaning 5min AND 15min both agree. If it shows WAIT or CONFLICT — do nothing. Patience is your biggest edge.

Confirm EMA crossover on MT4 matches signal
TradeWise says STRONG BUY → check MT4 M5 and M15 charts → EMA 8 must be above EMA 21 on BOTH. If yes — enter. If EMAs are tangled or crossing opposite direction — wait for next signal.

🤖 Auto-EA Code for MT4
// TradeWise MTF Agreement EA — paste into MetaEditor (F4)
extern string Sym = "XAUUSD";
extern double RiskPct = 0.5;
extern int StopPips = 10;
extern int TargetPips = 20;
extern int Magic = 20260601;

void OnTick() {
  if(OrdersTotal() > 0) return;
  // 5-minute signals
  double e8_5m = iMA(Sym,PERIOD_M5,8,0,MODE_EMA,PRICE_CLOSE,0);
  double e21_5m = iMA(Sym,PERIOD_M5,21,0,MODE_EMA,PRICE_CLOSE,0);
  double e8_5m_prev = iMA(Sym,PERIOD_M5,8,0,MODE_EMA,PRICE_CLOSE,1);
  double e21_5m_prev = iMA(Sym,PERIOD_M5,21,0,MODE_EMA,PRICE_CLOSE,1);
  double rsi5 = iRSI(Sym,PERIOD_M5,14,PRICE_CLOSE,0);
  // 15-minute signals
  double e8_15m = iMA(Sym,PERIOD_M15,8,0,MODE_EMA,PRICE_CLOSE,0);
  double e21_15m = iMA(Sym,PERIOD_M15,21,0,MODE_EMA,PRICE_CLOSE,0);
  double rsi15 = iRSI(Sym,PERIOD_M15,14,PRICE_CLOSE,0);
  // MTF Agreement logic
  bool buy5m = e8_5m > e21_5m && e8_5m_prev < e21_5m_prev && rsi5 < 65;
  bool buy15m = e8_15m > e21_15m && rsi15 < 65;
  bool sell5m = e8_5m < e21_5m && e8_5m_prev > e21_5m_prev && rsi5 > 35;
  bool sell15m = e8_15m < e21_15m && rsi15 > 35;
  // Only trade when BOTH timeframes agree
  if(buy5m && buy15m) {
    double price=Ask, sl=price-StopPips*Point*10, tp=price+TargetPips*Point*10;
    OrderSend(Sym,OP_BUY,CalcLots(),price,3,sl,tp,"TW-MTF",Magic,0,clrGreen);
  }
  if(sell5m && sell15m) {
    double price=Bid, sl=price+StopPips*Point*10, tp=price-TargetPips*Point*10;
    OrderSend(Sym,OP_SELL,CalcLots(),price,3,sl,tp,"TW-MTF",Magic,0,clrRed);
  }
}
double CalcLots() {
  double risk=AccountBalance()*RiskPct/100;
  double pipVal=MarketInfo(Sym,MODE_TICKVALUE)*10;
  return NormalizeDouble(risk/(StopPips*pipVal),2);
}
