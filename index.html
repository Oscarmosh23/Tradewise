🔧 How to Execute Signals on MT4
01
Open M5 and M15 charts side by side
Two chart windows — same asset, M5 and M15. Add EMA 8 (blue) and EMA 21 (red) to both charts. Your visual confirmation: EMA 8 must be above EMA 21 on BOTH charts for a BUY signal.
M5 + M15 · EMA 8 + EMA 21
02
Wait for TradeWise STRONG or NORMAL signal with 4/5 or 5/5
Only act on STRONG BUY, STRONG SELL, NORMAL BUY, or NORMAL SELL. If it shows WAIT — do nothing. Check every 5-10 minutes for new signals during London/NY session.
4/5 or 5/5 only — ignore everything below
03
Confirm on MT4 before entering
TradeWise says STRONG BUY → open MT4 → check EMA 8 is above EMA 21 on BOTH M5 and M15 → if yes, enter. If EMAs do not confirm — skip this signal and wait for the next one.
Both charts must confirm before entry
04
F9 → set lot size, stop loss, take profit → execute
Use lot size from Risk Calc tab. Stop loss = pips from signal card. Take profit = 2x stop pips. After entry set alarm at +10 pips. When alarm fires — move stop to entry price (free trade).
F9 → lots → SL → TP → Buy/Sell
05
Stop after 3 consecutive losses — no exceptions
Three losses means conditions changed or you are in a choppy market. Close MT4, step away for 30 minutes minimum. Come back fresh. Never revenge trade. The next session will have better setups.
3 losses = stop for 30 minutes
🤖 MT4 EA — Auto-Execute TradeWise Signals
// TradeWise Scalper Pro EA — 5-Layer MTF Agreement
// Paste into MT4 MetaEditor (F4) → Compile (F5) → Attach to chart
extern string Sym = "XAUUSD";
extern double RiskPct = 0.5;
extern int StopPips = 10;
extern int TargetPips = 20;
extern int MinLayers = 4; // 4=NORMAL, 5=STRONG only

void OnTick(){
  if(OrdersTotal()>0) return;
  int score=calcScore();
  if(score>=MinLayers) executeBuy();
  if(score<=-MinLayers) executeSell();
}
int calcScore(){
  int s=0;
  double e8_5=iMA(Sym,PERIOD_M5,8,0,MODE_EMA,PRICE_CLOSE,0);
  double e21_5=iMA(Sym,PERIOD_M5,21,0,MODE_EMA,PRICE_CLOSE,0);
  double e8_15=iMA(Sym,PERIOD_M15,8,0,MODE_EMA,PRICE_CLOSE,0);
  double e21_15=iMA(Sym,PERIOD_M15,21,0,MODE_EMA,PRICE_CLOSE,0);
  double e8_1h=iMA(Sym,PERIOD_H1,8,0,MODE_EMA,PRICE_CLOSE,0);
  double e21_1h=iMA(Sym,PERIOD_H1,21,0,MODE_EMA,PRICE_CLOSE,0);
  double rsi5=iRSI(Sym,PERIOD_M5,14,PRICE_CLOSE,0);
  double rsi15=iRSI(Sym,PERIOD_M15,14,PRICE_CLOSE,0);
  double macdM=iMACD(Sym,PERIOD_M5,12,26,9,PRICE_CLOSE,MODE_MAIN,0);
  double macdS=iMACD(Sym,PERIOD_M5,12,26,9,PRICE_CLOSE,MODE_SIGNAL,0);
  if(e8_5>e21_5) s++; else s--; // Layer 1: EMA 5min
  if(e8_15>e21_15) s++; else s--; // Layer 2: EMA 15min
  if(rsi5<45) s++; else if(rsi5>55) s--; // Layer 3: RSI 5min
  if(rsi15<45) s++; else if(rsi15>55) s--; // Layer 4: RSI 15min
  if(e8_1h>e21_1h) s++; else s--; // Layer 5: 1H trend
  return s;
}
void executeBuy(){
  double p=Ask,sl=p-StopPips*Point*10,tp=p+TargetPips*Point*10;
  OrderSend(Sym,OP_BUY,calcLots(),p,3,sl,tp,"TW5L",0,0,clrGreen);
}
void executeSell(){
  double p=Bid,sl=p+StopPips*Point*10,tp=p-TargetPips*Point*10;
  OrderSend(Sym,OP_SELL,calcLots(),p,3,sl,tp,"TW5L",0,0,clrRed);
}
double calcLots(){
  double r=AccountBalance()*RiskPct/100;
  double pv=MarketInfo(Sym,MODE_TICKVALUE)*10;
  return NormalizeDouble(r/(StopPips*pv),2);
}
