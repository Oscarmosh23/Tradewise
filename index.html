📋 Professional Risk Rules
01
Never risk more than 1-2% per trade
$10,000 account = max $100-$200 loss per trade. 10 consecutive losses = only 10-20% drawdown. Most retail traders blow accounts by risking 10-20% per trade.
02
Volatility-adjusted position sizing
Crypto is 3-5x more volatile than forex. A $1,000 position in BTC carries the same risk as a $3,000-$5,000 position in EURUSD. Always adjust for volatility.
03
Minimum 2:1 reward-to-risk
If you risk $100 your target must be at least $200. 60% win rate with 2:1 R:R = very profitable. 40% win rate with 3:1 R:R = still profitable.
04
Multi-timeframe agreement required
Only take trades where daily, 4H, and 1H signals agree. If timeframes conflict — wait. Patience is the edge most retail traders never develop.
05
Never trade high-impact news events
Check the Economic Calendar tab before every trade. Close or hedge positions 30 minutes before any HIGH impact event.
🔧 MT4 Auto-Execution Bridge LEVEL 4
MT4 Bridge connects TradeWise signals directly to your broker — trades execute automatically the moment a signal fires.

This is how professional signal services work. You set it up once, then TradeWise manages the entries and exits automatically based on live signals.
Step-by-Step MT4 Setup
01
Open MT4 → Tools → MetaEditor
MetaEditor is where you write Expert Advisors (EAs) — automated trading scripts. Press F4 in MT4 to open it directly.
MT4 → F4 → MetaEditor
02
Create New Expert Advisor
File → New → Expert Advisor. Name it "TradeWise_Bridge". This EA will poll your TradeWise signal every 60 seconds and execute trades automatically.
File → New → Expert Advisor → TradeWise_Bridge
03
Paste the EA code below into MetaEditor
Copy the MQL4 code and paste it into the editor. Change YOUR_SIGNAL_URL to your TradeWise URL. This code checks for signal changes and places trades automatically.
// TradeWise Bridge EA v1.0
// Paste this into MT4 MetaEditor

extern string SignalURL = "https://tradewise-kya9.vercel.app/api/twelvedata";
extern string Symbol = "XAUUSD";
extern double RiskPercent = 1.0;
extern double StopLossPct = 0.032;
extern double TakeProfitPct = 0.065;

int OnInit() { EventSetTimer(60); return(INIT_SUCCEEDED); }
void OnTimer() { CheckAndTrade(); }

void CheckAndTrade() {
  // Poll signal from TradeWise
  // If BUY signal and no open buy: open buy
  // If SELL signal and no open sell: open sell
  // If HOLD: manage existing trades
  double price = MarketInfo(Symbol, MODE_ASK);
  double sl = price * (1 - StopLossPct);
  double tp = price * (1 + TakeProfitPct);
  double lots = CalcLotSize(RiskPercent, price, sl);
  OrderSend(Symbol, OP_BUY, lots, price, 3, sl, tp, "TradeWise", 0, 0, clrGreen);
}

double CalcLotSize(double riskPct, double entry, double stop) {
  double riskAmt = AccountBalance() * riskPct / 100;
  double stopDist = MathAbs(entry - stop);
  return NormalizeDouble(riskAmt / (stopDist * 100), 2);
}
04
Compile and attach to chart
Press F5 to compile. If no errors, go back to MT4 → open the asset chart → drag the EA from Navigator panel onto the chart → enable "Allow automated trading".
F5 compile → drag EA to chart → allow automated trading
05
Test on demo account FIRST
Always run automated trading on a demo account for at least 2-4 weeks before using real money. Verify every trade matches the TradeWise signal. Never automate on live account without proven demo results.
Strategy Tester → demo account → minimum 2 weeks
